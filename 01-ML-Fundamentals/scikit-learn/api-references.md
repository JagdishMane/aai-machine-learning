# API References

![User Guide](https://scikit-learn.org/stable/user_guide.html#user-guide)
![API Reference](https://scikit-learn.org/stable/api/index.html)

- `sklearn.datasets`: Access standard datasets like iris and digits.
- `sklearn.model_selection`: Tools for cross-validation and hyperparameter tuning.
- `sklearn.preprocessing`: Functions for data pre-processing and normalization.
- `sklearn.linear_model`: Includes models like Linear Regression and Logistic Regression.
- `sklearn.svm`: Support Vector Machines.
- `sklearn.tree`: Decision Trees.
- `sklearn.ensemble`: Ensemble methods like Random Forests and Gradient Boosting.
- `sklearn.cluster`: Clustering algorithms such as KMeans.
- `sklearn.metrics`: Performance metrics and scoring functions.
